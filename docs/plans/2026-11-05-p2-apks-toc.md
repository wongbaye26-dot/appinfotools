# P2-5：APKS `toc.pb` 分包选择

> 日期：2026-11-05

## 改动

新增 `lib/utils/apks_toc.dart`：

- 最小 protobuf wire-format 解码；
- 读取 `TableOfContents.entry[].path`；
- 不引入 protobuf 依赖。

`XapkInstaller`：

- `getSplitApks` / `install` 的优先级改为：
  1. `toc.pb`（APKS）；
  2. `manifest.json` 的 `split_apks`；
  3. 目录里全部 `.apk`。
- `toc.pb` 里声明的条目会先与归档实际条目求交集，避免列出不存在的文件。

## 结果

APKS 不再在缺 manifest 时把 `universal.apk` / `standalones/*` 一起塞给
`adb install-multiple`；默认分包清单来自 bundletool 的 TOC。

## 测试

- `test/apks_toc_test.dart`：解析两个 entry、空输入/垃圾输入；
- `test/xapk_installer_test.dart`：构造带 `toc.pb` 的 APKS，断言只返回
  TOC 列出的 base + split，`universal.apk` 被排除。

## 仍未做

- TOC 里其他字段（版本、ABI 等）未建模；
- 没有真实 `.apks` 大包夹具。
